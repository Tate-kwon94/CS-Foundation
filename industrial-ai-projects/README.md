# Industrial AI Projects

Portfolio projects at the intersection of plant engineering and software — the domain
edge behind this repository.

Each project gets its own folder with a README (problem → approach → architecture →
results), source code, and sample data.

## Confidentiality

These projects are *inspired by* problems I have encountered as an engineer, never
copied from work. No employer or project material appears here: no internal documents,
drawings, inspection records, contract values, or design specifics. Every project uses
**synthetic data** and a **generalized problem statement**, and is built independently
of any employer system.

```markdown

One line: what it does and for whom.

The general engineering problem (no employer specifics).

## Approach & Architecture
Diagram + key decisions and trade-offs.

## Results
Screenshots, metrics, what I'd do differently.

## Run it
Setup + usage. Data: synthetic, generated by `scripts/`.
```
