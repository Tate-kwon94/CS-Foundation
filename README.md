## Ground rules

1. **No-AI rule for fundamentals.** In `python-basics/`, `data-structures/`, and `leetcode/`, every line is hand-written. AI is allowed only *after* solving, for review and comparison. (I can already ship code with AI assistance — this repo exists to build what AI can't give me: the ability to reason about code on my own.)
2. **Every study session ends with a commit.** Small is fine. Zero-commit weeks get a written retro in the study log.
3. **English for portfolio-facing docs** (this README, project READMEs), Korean for personal study notes.

## Repo rules (academic integrity)

Coursework code from the UIUC Accelerated CS Fundamentals specialization (assignments, challenge problems) is **never** committed here — that would violate the course honor policy. What lives in this repo:

1. **Weekly study logs** (`docs/study-log/`) — the consistency record
2. **Concept notes** written in my own words (e.g. `data-structures/cpp-vs-python.md`)
3. **My own re-implementations** — data structures rebuilt from scratch on different examples, usually from my own engineering domain

The point of this repo is not to show that I completed a course. It is to show how I think, week by week.
